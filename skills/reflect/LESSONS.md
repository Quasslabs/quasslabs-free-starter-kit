# Lessons — reflect

## 2026-06-11 — initial release

- The four-section format (worked / friction / near-misses / actions) catches more useful signal than free-form retros. Near-misses are the highest-value section because they reveal unguarded risks.
- Append, never overwrite. LESSONS.md is the project's longitudinal record; clobbering it is the worst possible failure mode.
- Date-stamp every entry. Undated retros are useless six months later when you're trying to remember which sprint introduced a process change.
- A retro that produces zero actions is a smell — either the session was trivial (skip the retro) or the lessons weren't specific enough.
